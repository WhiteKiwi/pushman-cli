# Security Policy

Pushman CLI is pre-release software and does not yet publish supported release branches.

Do not open a public issue for a suspected vulnerability or include tokens, message content, private hostnames, local paths, or unredacted logs in an issue. Use GitHub private vulnerability reporting when available; otherwise contact the repository owner privately through their GitHub profile with only the minimum details needed to establish a secure channel.

Never submit a real `PUSHMAN_TOKEN`, paired credential, OAuth assertion, signing material, or production configuration.
